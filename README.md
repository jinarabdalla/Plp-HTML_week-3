# My Budget Tracker — Visual Design Challenge

This project presents a visual redesign of the Budget Tracker for the Power Learn Project CSS challenge.

## Files
- `index.html` — the page structure for the Budget Tracker heading, Add Expense form, and expenses table.
- `style.css` — the color palette, Google Fonts typography, form and table styles, card layout, spacing, borders, and responsive styling.

## Design choices
- **Colors:** deep green and mint with a light background for a calm finance dashboard.
- **Typography:** Poppins for headings and DM Sans for body text and controls, loaded from Google Fonts.
- **Forms and table:** consistent input sizes, focus states, a strong table header, borders, and alternating row colors.
- **CSS box model:** margins, padding, borders, rounded corners, and subtle shadows separate the three main cards.

## How to view
Open `index.html` in a browser. An internet connection is needed to load Google Fonts; fallback fonts are provided.

## Note
This submission focuses on visual styling. The Add Expense button is present for the assignment layout; expense-entry functionality is not implemented in this CSS-only challenge.
